# 古文単語四択テスト作成アプリ

## 🌐 アプリケーションはこちら
[https://kotan315-test.vercel.app](https://kotan315-test.vercel.app/)

## 💡 開発の背景
このプロジェクトは、私が通っている塾での学習体験がきっかけで開発しました。
古文単語の習得に励む中で、担当の先生が「四択形式の演習問題作成に苦慮されている」というお話を伺い、少しでも先生の授業準備の負担を軽減し、効率的な学習環境を作りたいと考えたことが開発の始まりです。先生の日頃の熱心なご指導に対する感謝を込めて、このツールを形にしました。

## 🎓 先生方・学習者の皆様へ
このアプリは、どなたでも自由にご利用いただけます。塾での授業の教材作成や、日々の学習の復習など、古文単語の演習が必要な場面でぜひ活用してください。

このアプリをより良くしていきたいと考えています。「こんな機能があったら便利」「ここをこう直してほしい」といったご意見やアイデアがございましたら、ぜひGitHubの **[Issues](https://github.com/taearimain-del/kotan315-test/issues)** にてお知らせください！

## 🛠 プロジェクトについて
このプロジェクトは [Create React App](https://github.com/facebook/create-react-app) を使用して構築されています。

## ⚙️ 利用可能なスクリプト

プロジェクトディレクトリで以下のコマンドを実行できます：

### `npm start`
開発モードでアプリを実行します。
[http://localhost:3000](http://localhost:3000) をブラウザで開いて確認してください。

### `npm test`
対話型のウォッチモードでテストランナーを起動します。

### `npm run build`
本番環境用にアプリを `build` フォルダへビルドします。

### `npm run eject`
**注意：これは不可逆的な操作です。** 設定を完全にカスタマイズしたい場合のみ使用してください。
